# Visual QA Checklist

Date: 2026-07-02

## Desktop checks

- [x] Timeline displays full-day rows with 30-minute boundaries.
- [x] Hour labels appear at each :00 row.
- [x] Task cards are readable on cool-color backgrounds.
- [x] Add/Edit/Delete actions visibly update timeline after save/delete.

## Mobile checks

- [x] Header and timeline fit narrow viewport without horizontal overflow.
- [x] Dialog actions remain usable and primary save button is full width.

## Accessibility and readability notes

- Cool-color palette uses moderate contrast and low saturation.
- Error messages are shown in the dialog with role="alert".
