# Profiles

これは一日の予定を作る自作ツールです

## 使い方

開発用ソースは `src/` 配下にモジュール分割されています（`index.html` を開くにはローカルサーバーが必要です）。

サーバーなしで単体のHTMLファイルとして使いたい場合は、ビルドスクリプトで1ファイルに結合できます。

```bash
npm run build
```

`dist/index.html` が生成されるので、これをダブルクリックしてブラウザで開くだけで使えます（サーバー起動不要）。`src/` 配下を変更した場合は、`npm run build` を再実行して `dist/index.html` を作り直してください。
